# NeuralForge

A polished product studio landing page for teams that need web products, automation and dependable delivery. The experience uses a cinematic dark visual system, responsive layouts, interactive motion and a clear conversion path.

## Highlights

- Responsive single-page product site
- Animated ambient background and particle canvas
- Service, process, guarantee, stack and project sections
- Accessible semantic structure and mobile navigation
- Zero build step and zero runtime dependencies

## Usage

Open `index.html` in a browser, or serve the directory with any static file server, e.g.:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`. The site can also be deployed directly with GitHub Pages.
